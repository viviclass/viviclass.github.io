# 薇光 AI 課堂｜圖片與 10 秒口播影片提示詞工具

這份教材部署在既有的 `viviclass/viviclass.github.io` GitHub Pages 儲存庫下，**不覆蓋原有網站首頁**。

## 學員網址

- 圖片提示詞： https://viviclass.github.io/ai-prompt-studio/image/
- 10 秒影片提示詞： https://viviclass.github.io/ai-prompt-studio/video/
- 教學入口： https://viviclass.github.io/ai-prompt-studio/

## 內容與使用方式

1. 點選 ViVi 專屬預設或其他產業範例。
2. 七個欄位保留「素材庫下拉選項」及「自由輸入」兩種方式。自由輸入優先；另有補充文字欄。
3. 圖片頁產生主視覺提示詞，可一鍵複製／下載 TXT，或把選好的資料帶到影片頁。
4. 影片頁根據人物、產業、場景及商品產生適合的 10 秒口播；按「換一句」切換台詞，也能自行輸入，手動台詞不會被欄位修改覆蓋。
5. 產生完整影片提示詞，複製或下載 TXT；至支援人物口播的影片平台另行上傳人物照片或圖片作為首幀。

## 技術與注意事項

- 純前端 HTML、CSS、JavaScript，無 API Key、無伺服器成本。
- 本工具不會上傳人像，也不會自行生成圖片與影片。
- 自動口播採內建模板規則，不宣稱使用 AI API；每次生成的語句仍需自行檢查長度、商品資訊及品牌用語。
- GitHub Pages 的實際生效時間取決於既有儲存庫的發布流程。


## 男生／女生人物設定（2026-11-03）

圖片頁和影片頁均新增「人物呈現」下拉選項：依上傳照片（預設）、男生、女生。**原本七格素材庫、每格自填與補充欄位不變。**

- 依上傳照片：不擅自推斷人物性別，保留照片本人造型與身份。
- 男生：圖片提示詞明確保留男性本人形象；影片提示詞另外加入自然成年男性聲線。
- 女生：圖片提示詞明確保留女性本人形象；影片提示詞另外加入自然成年女性聲線。
- 新增「男性版｜AI 生活導演」品牌示範，與 ViVi 女性形象預設並存；不會強制男性穿戴 ViVi 的長波浪髮或花朵耳環。
- 如果男學員從 ViVi 女性形象範本直接切換「男生」，系統會移除範本內明顯衝突的女性造型補充。

人物呈現控制的是提示詞描述，不會在本頁自動辨識照片或改動真實照片；口播生成工具仍需學員自行在支援人物口播的影片平台上測試聲線與口型效果。
