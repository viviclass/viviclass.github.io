你會走過這七步

點每個圈圈，看那一步要做什麼 👇

先用白話解釋一次：Skill 就是「一份 AI 看得懂的工作 SOP」。你把自己做事的方法寫清楚，之後每次開新對話，丟給 AI，它就照你的方法做，不用每次重新解釋。

什麼事情適合做成 Skill？

符合下面條件越多，越適合：

  • 一週至少會做 2～3 次
  • 每次處理流程差不多
  • 每次都要重新跟 AI 解釋
  • 最後通常有固定的輸出成果

例如：開會紀錄、社群文案、圖片提示詞、商品介紹、短影音腳本、客戶需求整理、活動企劃、課程通知

Skill 不需要從最複雜的事情開始。越常做、越重複的事情，越值得先做成 Skill。

常見問題

Skill 是什麼？

Skill 可以先理解成一份 AI 看得懂的工作 SOP。把你做事的方法寫清楚，之後每次開新對話交給 AI，它就照你的方法做，不用每次重新解釋。

完全沒做過 Skill，可以自己做嗎？

可以。不用從零寫，找一次你在 ChatGPT 最滿意的成功對話，請 GPT 拆成流程、打包成 Skill 就行。整個流程是找、找、拆、包、裝、測、改七步，每一步都有可直接複製的指令。

什麼事情適合做成 Skill？

一週至少會做 2～3 次、每次處理流程差不多、每次都要重新跟 AI 解釋、最後有固定輸出成果的事。例如開會紀錄、社群文案、圖片提示詞、短影音腳本、客戶需求整理。

我的 ChatGPT 沒有 Skills 功能怎麼辦？

不同帳號、方案、裝置或工作區的介面可能不同。沒有安裝功能時，仍可新開對話、上傳 .md 檔，並說「請依照這份 Skill 執行接下來的任務」；不能上傳就貼上 Skill 內容。差別是只有 MD 時，每次新對話都要重新上傳或貼入。

為什麼要開新對話測試 Skill？

原本做 Skill 的聊天室已經知道前面所有資訊，測試會失真。要用正常案例和故意少給資料的案例各測一次，確認它缺資料時會先問你，而不是自己猜。

Skill 測出問題要怎麼改？

要改 Skill 本體的規則，不是只改這一次的答案。改完要重新輸出最新版 .md、更新安裝的版本，再開新對話測一次，同一個問題不再出現才算改成功。

安裝完成後怎麼用？

方法 1｜直接說需求

Skill 安裝後，可以直接在新對話說需求，ChatGPT 可依任務內容判斷是否使用相關 Skill。

方法 2｜明確指定 Skill

如果希望這一次明確使用某個 Skill，輸入：@技能名稱 ＋ 需求

例如：@開會紀錄 幫我整理下面這場會議。

想明確指定 Skill → 用 @技能名稱

@ 和 / 的差別

  • @技能名稱：明確指定這次要使用哪一個 Skill。課堂主要教這個。
  • /：叫出目前介面可使用的命令／功能選單；部分介面可能顯示已啟用 Skill，但不要當成 /技能名稱 在所有裝置都一定能用。

如果找不到 Skills 功能

不同帳號、方案、裝置或工作區的介面可能不同。如果目前沒有 Skill 安裝功能，仍可使用 .md：

  1. 新開一個對話，上傳 .md，並說：「請依照這份 Skill 執行接下來的任務。」
  2. 如果不能上傳，就貼上 Skill 內容，並說：「請閱讀並依照以上 Skill 規則執行後續任務。」
有安裝新對話可以直接使用／指定 Skill。
只有 MD新對話需要重新上傳或貼入。

STEP 6 / 7

測 Skill

現在要做用上一步裝好的 Skill，在全新對話連測兩次：一次正常、一次故意少給資料。
不要在原本製作 Skill 的聊天室測。那個 GPT 已經知道前面所有資訊，測試會失真。不要相信第一次成功，換一個新對話測。

TEST 1｜正常測試

在新對話裡，用 @技能名稱 叫出剛裝好的 Skill（沒有安裝功能的人，就上傳或貼入 MD），再給它一個新的正常案例。檢查：

TEST 2｜故意少給資料

第二次測試時，故意不要把資料全部給完。例如 Skill 原本需要：活動名稱、日期、地點、對象；這次故意不給日期。

❌ 不及格AI 自己猜了一個日期 → Skill 還需要修
✅ 及格AI 告訴你缺少日期、需要確認 → 判斷規則正常
不是只測它會不會做，還要測它知不知道「什麼時候不能做」。

改 Skill

現在要做測試出錯時，不要只說「幫我改一下」。貼下面這段，請 GPT 修改 Skill 本體。
不是改答案，是改規則。只改答案，只修這一次；改規則，才能改善未來每一次。

先判斷問題屬於哪一類

輸入問題需要的資料沒有寫清楚
流程問題AI 執行順序有問題
規則問題沒有定義什麼能做、不能做

輸出問題格式、長度、結構不符合需求
檢查問題做完沒有重新驗收
修改 Skill把【請在這裡貼上問題】換成你剛測到的問題再送出。
剛剛測試這個 Skill 時，出現以下問題：

【請在這裡貼上問題】

請不要只修改這一次的答案。

請先判斷問題出在 Skill 本體的哪一個部分：

- 輸入條件
- 執行流程
- 判斷規則
- 必須確認的資訊
- 輸出格式
- 禁止事項
- 最終檢查

請幫我修改 Skill 本體。

修改後請告訴我：

1. 原本哪裡有問題
2. 修改了哪一條規則
3. 為什麼這樣修改
4. 未來如何避免再次發生

最後請重新輸出完整最新版 Skill。
改完要再測一次。開一個新的測試，同一個問題不再出現，才代表這次修改成功。

Skill 改完，也要更新安裝版本

如果 Skill 本體已經從 v1 改成 v2：

  1. 重新輸出最新版 .md
  2. 更新／重新匯入 Skill
  3. 確認舊版本是否需要停用
  4. 再開新對話測試
  5. 確認目前使用的是最新版

版本管理

每次重要修改後留一個版本，檔名像這樣：

開會紀錄_v1.md　開會紀錄_v2.md　開會紀錄_v3.md

建議記錄：Skill 名稱、版本、修改日期、修改原因、修改內容。範例：

開會紀錄 v2｜2026/10/08
修改原因：AI 在缺少會議日期時自行產生日期。
修改內容：新增「未提供日期時，必須先詢問使用者，不得自行推測。」
