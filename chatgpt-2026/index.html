2026-09-08

圖像 2.5：生圖更快、四個新功能

OpenAI 推出 ChatGPT Images 2.5，生成速度比 2.0 版快最多 50%，光線更自然、材質細節更細緻。多輪編輯（一直請 AI 改這改那）之間也更不容易跑掉。

新增四個好用的功能：

  • Templates（常用版型模板）：海報、產品照這類常見格式直接套用。
  • Sketch（手繪參考）：自己畫幾筆當構圖參考，AI 照著畫。
  • 圖片留言修改：直接在圖片上標註「這裡要改」，AI 只動那一塊。
  • Prompt 分享：把生成這張圖的提示詞分享出去，別人可以直接沿用。

⚠️ Templates 目前尚未在 ChatGPT Work 提供，功能仍可能依平台分批推出，看不到不代表你的帳號有問題。

02
同一次更新，2026-09-08

人物一致性：換場景更不容易換臉

這是這次更新裡我最在意的一項，因為短影音創作者最頭痛的就是「換一個場景，人就變了」。圖像 2.5 官方明確加強了「多輪編輯之間的一致性」與「保留參考照片裡的主體細節」——也就是你上傳一張角色參考照後，接下來每一次生圖都能盡量維持五官、髮型與體態。

一致性提高，但仍不保證每張完全相同。這點我要講清楚，不要讓妳生了十張都不滿意還以為是自己不會下指令。實務上要這樣做：先給 AI 一張清楚的正面參考照，用文字固定住外型特徵（臉型、髮色、招牌配件），之後每一次生圖都附上同一張參考照，只描述「場景」和「動作」要改變的部分，不要重新描述長相。

下面指令區有現成的角色卡指令可以直接複製。

03
最多人踩到的一項

GPTs 建立規則改變了

如果妳最近想建一個 GPT 卻找不到按鈕、或按了說沒有權限——不是妳的帳號壞了，是規則改了。

  • Free／Go／Plus／Pro 個人帳號：不能新建或發布 GPT。付費也一樣，這一項跟方案貴不貴無關。
  • 已經建立的 GPT 仍然可以使用，不會消失。
  • 符合方案與權限時，仍然可以編輯既有的 GPT。
  • Business／Enterprise／Edu：可依工作區的權限設定建立與發布。
  • 手機只能「使用」GPT，不能「建立」GPT。在手機上找不到建立入口是正常的。

那平常靠 GPTs 存提示詞的人怎麼辦？改用自訂指令、Projects、提示詞庫三種替代做法，我另外寫了一整頁：GPTs 建不了了怎麼辦？提示詞庫替代方案。指令區也有一組「不能建 GPT 時的替代工作流」可以直接複製。

04
2026-09-03 發表，分批推出

GPT-6 Astra ＋ Work

OpenAI 的旗艦模型 GPT-6 Astra 於 2026-09-03 發表並開始分批推出（官方公告當天仍註明尚未全面開放，所以看不到也可能只是還沒輪到妳）。它主打研究能力、寫程式、電腦操作、多步驟長任務，以及文件／試算表／簡報產出，適合「一次講完、AI 自己跑很多步驟」的工作。

誰能用 Astra？

  • Plus：可在 ChatGPT Work 與 Codex 使用 Astra。
  • Pro、Business、Enterprise：另可在聊天視窗選用 GPT-6 Pro（就是 Astra 的選單顯示名稱）。
  • Go：雖然是付費方案，但不包含 Astra。
  • Free：完全不含，加購也沒有用。
  • Enterprise：能不能用取決於工作區管理員設定與模型權限，找不到就去問管理員。

Astra 用量算在原本的訂閱額度裡，用完可以另外加購。

Work 怎麼打開、能做什麼

入口：桌機 App 點左上角選單 → ChatGPT → 用上方切換鈕在「Chat」和「Work」之間切換；手機從畫面最上方往下拉，選擇 Work。

資格限制要看清楚：登入網站與身分驗證功能目前適用 Plus、Pro；Webhook 任務也有方案與支援 App 的限制。付款、預約這類重要操作前，系統仍會要求你確認，不會自己下去。

05
2026-09-10 新增三家雲端

Library ＋ 雲端檔案 ＋ Projects

Library 可以連的雲端硬碟從一家變四家：

  • Box
  • Dropbox
  • SharePoint
  • Google Drive（原本就有）

連上之後可以直接在 Library 瀏覽雲端硬碟裡的檔案與資料夾，包含別人分享給你的項目。目前以網頁版分批推出，手機版後續提供——手機上還看不到是正常的。

Projects 記憶設定可改（2026-08-14）：符合資格且未共用的專案，可以直接切換「預設記憶」與「僅限本專案記憶」，不用重開一個新專案；共用中的專案則固定維持「僅限本專案記憶」。

06
新功能

Library 可以分享了

以前 Library 是自己一個人的，現在可以開放給別人。對有團隊、有助理、有學員的人來說這是真的會用到的功能：

  • 邀請指定對象：不是全部公開，指定誰能進來。
  • Viewer／Editor 兩種權限：只能看，或可以改。
  • 可以分享給整個工作區。
  • Shared with me：別人分享給你的，集中在這裡管理。
  • 權限可以隨時調整或移除。

⚠️ 分享之前，這件事一定要知道

  • 上傳到共享資料夾的檔案，屬於資料夾的「擁有者」，不是上傳的人。
  • 上傳者身分仍然會被記錄，誰傳的看得出來。
  • 如果資料夾擁有者移除妳的權限，檔案仍然留在對方的資料夾裡，而妳會失去存取權。

所以：重要的母檔、原始素材，自己一定要另外留一份。不要把唯一一份丟進別人的共享資料夾。

2026-09-09

Voice 語音：改用跟文字一樣的模型

語音模式這次的改動比看起來大：

  • 遇到需要搜尋或複雜推理的問題時，可以使用 GPT-5.6 或 GPT-6 Astra。
  • 模型與推理控制改成與文字聊天一致——你在文字那邊怎麼選，語音這邊就怎麼選。
  • 原本 Voice 獨立的 Instant／Medium／High 等級已取消，不用再另外調一套。
  • 可用模型與額度依方案而定。

另外 2026-08-07 起，語音對話中可以直接上傳檔案並分析內容，也能延續你在某個 Project 裡的資料與指示。

08
給創作者的實戰

創作者的實際工作流

功能講完了，但「什麼時候用哪一個」才是重點。這是我自己在跑的順序：

  1. Images 2.5　生成與修改內容。角色參考照固定一張，修改用圖片留言直接標在圖上。
  2. Projects　分開管理角色、課程與品牌。一個專案一件事，記憶不會互相污染。
  3. Library／雲端硬碟　保存母檔與素材。Box／Dropbox／SharePoint／Google Drive 挑你本來就在用的那一家。
  4. Library 分享　團隊與學員協作，設好 Viewer／Editor，母檔自己另外留一份。
  5. GPTs　教學前先確認學員的帳號類型。個人帳號建不了，課程設計要先繞過這一關。
  6. Work　處理跨網站或多步驟任務，注意方案資格限制。

排查為什麼老師有我卻沒有

照順序檢查，通常前兩步就會找到答案。

  1. 先確認你是不是在「一般聊天視窗」找 Astra。Plus 方案的聊天視窗本來就看不到，要切到 Work 或 Codex，這是最常見的誤會，不是你的帳號壞了。
  2. 檢查自己的方案。聊天視窗版的「GPT-6 Pro」只有 Pro／Business／Enterprise 才有；Go 雖然付費但不含 Astra。對照上面的表格確認一次。
  3. 建不了 GPT？那是規則改了，不是故障。Free／Go／Plus／Pro 個人帳號已經不能新建或發布，手機也不能建立。看上面第 3 節。
  4. 你是 Enterprise 用戶嗎？能不能用取決於工作區管理員設定與模型權限，找不到就去問管理員。
  5. 新功能看不到，先想「分批推出」。Astra 是分批推出、Library 雲端來源目前只有網頁版、Templates 還沒進 Work——這些都不是你的問題，等就好。

9 組可直接複製的指令

點開展開，按「複製這段」，貼到 ChatGPT 就能用，記得把 [ ] 裡的內容換成你自己的。

指令 1｜把照片修成產品質感圖（圖像2.5）

用在賣場照片、封面圖，讓光線和背景更乾淨，但保留主體不變。

請用我上傳的這張照片當參考，重新生成一張更乾淨、光線更自然的版本，保留照片裡主體的外觀與細節不要改變，只調整背景、光線與畫質。輸出成適合社群貼文使用的直式構圖。
指令 2｜同一張臉，換不同場景（人物一致性）

短影音、IG 系列圖最需要的指令，先附上角色參考照再貼這段。

這是我的角色參考照（已附上照片）。接下來每一次生圖都請盡量維持這張臉的五官、髮型與體態一致，只更換場景、服裝與動作。如果某個角度無法完全維持，請優先保住臉型與髮型。這一次請生成：[描述場景，例如：她坐在窗邊喝咖啡，午後陽光灑進來]。
指令 3｜一週內容排程（GPT-6 Astra 長任務）

在 Work 或有 GPT-6 Pro 的方案裡用，適合處理多步驟的規劃任務。

我是短影音創作者，帳號主題是[你的主題]。請幫我規劃接下來 7 天的發文排程，每天一個主題＋一句開場鉤子＋一個 CTA，並依照 TikTok／FB＋IG／Threads 三種平台的語氣分別給我文案重點，最後整理成一張表格。
指令 4｜讓 AI 幫你整理網站上的待辦（Work 模式）

先切到 Work 模式再貼這段。注意：登入網站功能目前適用 Plus、Pro。

幫我瀏覽 [你常用的網站，例如蝦皮賣家後台]，整理出這週待處理的訂單或留言清單，依照優先順序排好，並用條列式回報給我。

重要限制：僅讀取與整理，不要回覆、不要刪除、不要下單、不要付款；任何會造成外部變更的動作都先問我，等我說可以再做。
指令 5｜一次看完信箱與行事曆（Google 串接）

先連好你的 Google 帳號（可以同時連個人與工作），再貼這段。

幫我看我這週個人和工作兩個 Gmail 帳號裡，有沒有需要今天回覆的重要郵件，並對照我的 Google 日曆，提醒我今天還有哪些會議或待辦，整理成一份今日簡報給我。

重要限制：只整理郵件與行程，不要自動寄信、不要自動回覆、不要幫我接受或取消任何邀請。
指令 6｜短影音角色卡（拍系列用）

先建好角色卡，之後每次生圖或寫劇本都附上，角色比較不會跑掉。

幫我建立一張「角色卡」：角色名稱、外型特徵（臉型、髮型、招牌配件）、個性關鍵字、說話語氣，整理成一段固定描述。之後我每次生圖或寫劇本都會附上這張角色卡，請你讓角色的外型與個性在每一集盡量保持一致，不要自己加新的設定。
指令 7｜Library 團隊協作（新）

要把素材開放給助理或學員之前，先用這段把規則想清楚。

我要用 ChatGPT Library 的共享資料夾跟 [團隊成員／學員] 協作，內容是 [例如：課程素材、角色參考照、品牌圖庫]。

請幫我規劃：
1. 資料夾要怎麼分類，誰給 Viewer、誰給 Editor
2. 哪些檔案「絕對不能」只存在共享資料夾裡（因為檔案屬於資料夾擁有者，我被移除權限就會失去存取）
3. 我自己要另外備份哪些母檔、備份在哪裡
4. 列一份給成員看的使用規則，三條以內，白話。
指令 8｜不能建立 GPT 時的替代工作流（新）

個人帳號建不了 GPT 之後，用這段把原本想做的 GPT 改造成可用的方案。詳細做法看 GPTs 建不了了怎麼辦。

我原本想建一個 GPT，用途是 [描述你想要的 GPT 在做什麼]。但我的帳號現在不能新建 GPT。

請幫我改成不用 GPTs 也能跑的做法，給我三個版本：
1. 自訂指令版：我該在「自訂指令」裡寫什麼
2. Projects 版：專案要怎麼設定、要放哪些檔案、記憶要選哪一種
3. 提示詞庫版：一段可以每次複製貼上的完整提示詞

每個版本都要能直接複製使用，不要只講概念。
指令 9｜個人 IP 貼圖包

把自己或角色變成一組表情貼圖，存下來當限動或訊息回覆用。

請用我上傳的這張照片，幫我做一組 6 張的表情貼圖，包含：開心、加油、驚訝、比讚、思考、晚安，風格可愛簡約、線條乾淨，適合做成 iMessage 或 LINE 貼圖使用。

加碼順手好用的小功能

這幾個也是最近上的，沒有上面那些關鍵，但做起來很有成就感：

個人化貼圖包（2026-08-31）

把一張照片或一個想法變成一組貼圖，做完存下來用在 iMessage 或 WhatsApp。指令區第 9 組可以直接複製。

iPhone 鎖定畫面顯示 Voice（2026-08-31）

語音對話時內容會顯示在鎖定畫面，有 Dynamic Island 的機型也會同步顯示。

多組 Google 帳號（2026-08-28）

同一個對話可以同時連接個人與工作的 Gmail、日曆與聯絡人，不用切來切去。官方只寫明可以連接多組，沒有公布明確上限。

Projects 記憶切換（2026-08-14）

符合資格且未共用的專案可以直接切換記憶模式，不用重開新專案。

FAQ常見問題

為什麼我不能建立 GPT？

因為建立與發布 GPT 的資格改了。Free、Go、Plus、Pro 的個人帳號已經不能新建或發布 GPT；以前建好的 GPT 仍然可以繼續使用，符合方案與權限時也仍然可以編輯。Business、Enterprise、Edu 則可依工作區權限建立與發布。另外手機上只能使用 GPT，不能建立 GPT。想把常用提示詞收起來重複使用，改走自訂指令、Projects 或提示詞庫。

共享資料夾裡的檔案屬於誰？

屬於資料夾的擁有者，不是上傳的人。你上傳到共享資料夾之後，檔案會歸在該資料夾底下，同時系統仍會記錄是你上傳的。如果資料夾擁有者移除你的權限，檔案會留在對方的資料夾裡，而你會失去存取權。重要的母檔請自己另外留一份。

圖像2.5 新增了哪些功能？

四個：Templates（常用版型模板）、Sketch（手繪參考）、圖片留言修改、Prompt 分享。生成速度也比 2.0 版快最多 50%，光線與細節更自然。Templates 目前尚未在 ChatGPT Work 提供，功能仍可能依平台分批推出。

人物一致性真的可以完全一樣嗎？

一致性有提高，但仍不保證每張完全相同。圖像2.5 強化了多輪編輯之間的一致性，換場景比較不容易換臉，也更能盡量維持五官、髮型與體態。實務上仍建議每次都附上同一張角色參考照，只描述要改變的場景與動作。

為什麼我的 ChatGPT 看不到 GPT-6 Astra？

最常見的原因是你在「一般聊天視窗」找，而 Plus 的聊天視窗最高只到 GPT-5.6 Sol。Plus 可在 ChatGPT Work 與 Codex 使用 Astra；Pro、Business、Enterprise 另可在聊天視窗選用「GPT-6 Pro」。Go 雖是付費方案但不包含 Astra，Free 也完全不含。另外 Astra 是 9/3 發表後分批推出，也可能只是還沒輪到你。

GPT-6 Astra 跟 GPT-6 Pro 是同一個東西嗎？

是同一個模型。Astra 是官方公告用的模型代號，「GPT-6 Pro」是它出現在聊天視窗選單裡的顯示名稱。

Free 和 Go 方案的聊天模型是什麼？

都是 GPT-5.6 Luna，不是 Sol。這是 OpenAI 官方說明文件寫明的。

ChatGPT Work 模式要怎麼打開？可以做什麼？

桌機 App 點左上角選單 → ChatGPT → 用上方切換鈕在 Chat 和 Work 之間切換；手機從畫面最上方往下拉，選擇 Work。登入網站與身分驗證功能目前適用 Plus、Pro；Webhook 任務也有方案與支援 App 限制。付款、預約等重要操作前仍會要求確認。

Library 可以連哪些雲端硬碟？

2026-09-10 起新增 Box、Dropbox、SharePoint，加上原本的 Google Drive 共四種。目前以網頁版分批推出，手機版後續提供。

可以同時連接個人與工作的 Google 帳號嗎？

可以。2026-08-28 起，同一個對話可以同時連接多組 Google 帳號的 Gmail、日曆與聯絡人。官方只寫明可以連接多組，沒有公布明確的數量上限。

Voice 語音模式的模型有什麼改變？

2026-09-09 起，Voice 的模型與推理控制改成與文字聊天一致，原本 Voice 獨立的 Instant／Medium／High 等級已取消。遇到搜尋或複雜推理時可使用 GPT-5.6 或 GPT-6 Astra，可用模型與額度依方案而定。

Astra／GPT-6 Pro 的用量會另外收費嗎？

不會，用量算在你原本的訂閱額度裡，用完可以加購。免費方案完全不含 Astra，加購也沒有用。
