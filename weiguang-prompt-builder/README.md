# 薇光 AI 課堂｜提示詞產生器

ViVi 老師教學用網站，純前端、離線可用，不需 API Key、帳號或伺服器。

| 頁面 | 檔案 | 用途 |
|---|---|---|
| 首頁 | `index.html` | 選擇要做圖片或影片 |
| 圖片提示詞 | `image.html` | 圖生圖的高級商業主視覺提示詞 |
| 10 秒影片提示詞 | `video.html` | 人物親自口播的 10 秒圖生影片提示詞（含自動台詞） |

建議流程：先在圖片頁做出主視覺，再把生成圖作為影片首幀，到影片頁複製提示詞。

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `(root)`。

## 注意
這是離線素材庫規則組合版，不是線上 AI 語言模型。本站不會上傳照片，不使用分析追蹤或 Cookie。
