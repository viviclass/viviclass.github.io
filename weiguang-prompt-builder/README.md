# 薇光 AI 課堂｜圖片 × 10 秒口播影片提示詞產生器

ViVi 老師教學用單頁網站。**不需要 API Key、帳號或伺服器**，單獨開啟 `index.html` 即可使用。

## 主要功能

- **圖片、影片雙欄**：各自保有 7 格人物、產業、場景、動作、商品／服務、風格、比例。
- **素材庫與自訂欄位**：點選素材標籤會填入文字，也能自行打字與補充細節。
- **動態口播**：影片區的台詞依人物、產業、商品、場景或動作組成不同說法；「換一句」可輪換同情境的台詞。
- **保留手動控制**：直接改寫口播時會停止自動覆蓋；按「重新自動生成」即可恢復。
- **ViVi 專屬沒想法範例**：預設為「ViVi｜AI 生活導演」，還有「HowAI 課程招生」、「三寶媽的 AI 生活」兩個品牌版本。
- **學員產業快捷範例**：咖啡店、房仲、美業、健身、精品品牌。
- **提示詞輸出**：圖片與 10 秒影片可一鍵更新、複製、單獨下載 UTF-8 TXT，也可下載兩份。
- **手機／電腦友善**：桌面左右雙欄；手機可切換圖片與影片工作區。

> 注意：這是**離線素材庫規則組合版**，不是線上 AI 語言模型。影片口播實際秒數、中文口型同步與角色一致性由生成影片的平台決定。建議在生成前先朗讀台詞並確認可於 10 秒內完成。

## 本機使用

1. 解壓縮 ZIP。
2. 直接以 Chrome、Safari 或 Edge 開啟 `index.html`。
3. 先點選 ViVi 示範或學員產業快捷範例，再修改欄位。
4. 複製圖片提示詞到生圖平台，使用自己的照片生成主視覺。
5. 把生成圖作為影片平台的首幀／人物參考，再複製 10 秒影片提示詞。

圖片或人物的實際上傳，是在你選用的影像生成平台中完成；本網站不會上傳照片。

## GitHub Pages 部署

1. 在 GitHub 新增一個 Public Repository，例如 `weiguang-prompt-builder`。
2. 把 `index.html`、`README.md` 上傳至儲存庫**根目錄**。
3. 在 Repository → **Settings → Pages**，於 **Build and deployment** 選 `Deploy from a branch`。
4. Branch 選 `main`，資料夾選 `/(root)`，按 Save。
5. GitHub Pages 發佈後，開啟 Pages 顯示的網址。可以將網址分享給學員或放在 Notion。

建議不要放入私人照片、學員個資或有版權疑慮的素材。此程式無需收集個資。

## 自訂素材庫

以文字編輯器開啟 `index.html`：

- 搜尋 `const LIB=` 可修改各欄素材選項。
- 搜尋 `const data=` 可修改課堂快捷範例與 ViVi 專屬版本。
- 搜尋 `function voiceParts` 可修改各產業的 3 種自動口播句型。
- 搜尋 `DEFAULT_SPEECH` 可調整 ViVi 示範口播預設句。

### 品牌固定內容

- 品牌名稱：薇光 AI 課堂
- ViVi 角色定位：晚上是三寶媽，白天是 AI 生活導演。
- 標語：用 AI，替生活留一點光。
- 口播示例：用 HowAI，把生活拍成光！一張照片，也能拍出品牌感！

## 技術說明

純 HTML + CSS + JavaScript，零外部套件，不使用分析追蹤、Cookie 或第三方服務。TXT 下載含 UTF-8 BOM，方便在部分 Windows 文字編輯器正確顯示繁體中文。
