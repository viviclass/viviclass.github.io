讓 AI 用你自己的語氣
幫你寫貼文

一行指令，把發文助手裝進你自己的電腦。它會先學你怎麼講話，再幫你排這週要發什麼， 然後一次給你三個平台的文案。 你只要複製、貼上、發布。

01 裝好工具02 一行指令03 學我的語氣04 開始寫

文｜ViVi 老師・薇光AI課堂　|　最後更新：2026 年 8 月 27 日 整個安裝過程約 20 分鐘。卡住很正常，第一次裝軟體都會卡。

🎯 先看一下：裝完它會給你什麼

你說「幫我寫一篇，用我的口氣」，它一次交出三組文案。每一組都有標題、內文、置頂留言，因為三個平台吃的節奏根本不一樣。

  • A
    TikTok／抖音／YouTube Shorts短、直接，第一句就給結論。沒有鋪陳的空間。
  • B
    Facebook／Instagram有故事、有情緒，結尾放互動鉤子讓人留言。
  • C
    Threads聊天口吻，像跟朋友講話，不要排版成一篇文章。
先講清楚

三件事，免得你裝完才發現不是你要的

  • 它不會自動幫你發文。 文案給你，你自己貼。不碰你的帳號、不代登入、不排程。這是刻意設計的——自動發文的帳號風險要你自己承擔，新手不該從那裡開始。
  • 它不會編數字。 你沒給的數據，它會留白寫「（待補）」，不會生一個好看的數字出來給你用。
  • 它不保證爆款。 公式是提高機率，不是保證。真正讓你變強的是持續發、每篇都記錄、兩週回頭看一次。
⚠️ 手機裝不了，這是真的不行

這是「資料夾技能」格式，只有電腦上的指令列工具讀得到，也就是 Claude Code 和 Codex CLI。

  • ChatGPT 手機 App — 裝不了
  • ChatGPT 網頁版 — 裝不了
  • Claude 手機 App — 裝不了

手機的人請用我另外發的「一段提示詞」版本，那個貼進去就能用。

NO.01

先裝好工具

你需要準備這三樣：

  • 一台電腦　Windows 或 Mac 都可以
  • Claude Code 或 Codex CLI　兩個擇一就好，都有也行
  • 你自己寫過的 10–20 篇貼文　等一下要貼給它看

裝 Claude Code

打開 claude.com/claude-code，照網站上的說明安裝。

或者裝 Codex CLI

照 OpenAI 官方的 Codex CLI 說明安裝。兩個工具吃的是同一份技能檔，裝哪個都行。

確認裝好了沒

打開終端機（Mac 叫「終端機」，Windows 叫「PowerShell」），輸入 claude 或 codex，有跳出東西就代表成功了。

還需要一個 git

git 是下載程式用的工具。貼下面這行進終端機，有跳出版本號就是你已經有了：

檢查 git
在終端機／PowerShell 貼上，按 Enter
git --version
沒跳版本號、說找不到 git？
  • Windows：去 git-scm.com/download/win 下載安裝，一路按下一步就好，裝完把 PowerShell 關掉重開。
  • Mac：在終端機輸入 xcode-select --install，跳出視窗按「安裝」。
💡 卡在這一步很正常，第一次裝軟體都會卡，這不是你的問題。卡住就到小群裡問，把螢幕上的錯誤訊息截圖貼上來，不要自己硬撐。
NO.02

一行指令，裝上發文助手

找到你的系統，按「複製」，貼到終端機按 Enter。只要一行，沒有第二步。

🪟 Windows
打開 PowerShell 貼上
irm https://raw.githubusercontent.com/viviclass/vivi-social-post/main/install.ps1 | iex
🍎 Mac
打開「終端機」貼上
curl -fsSL https://raw.githubusercontent.com/viviclass/vivi-social-post/main/install.sh | bash
✓ 看到兩個綠色勾勾就成功了

它會同時裝進 Claude Code 和 Codex 兩個資料夾，你之後用哪一個都叫得動。

如果你以前裝過舊版，它會先幫你備份再蓋新的，你的語氣卡不會不見。

想知道它到底裝到哪裡去了？
  • Claude Code 讀的是 ~/.claude/skills/vivi-post
  • Codex CLI 讀的是 ~/.agents/skills/vivi-post

Windows 的 ~ 就是 C:\Users\你的名字。所有檔案都在你自己電腦裡，不想要就直接刪掉那個資料夾。

NO.03

打開來，用中文跟它講話

打開 Claude Code 或 Codex，不用記任何指令，直接打這句：

學我的語氣 它會請你貼上自己寫過的貼文。貼 10–20 篇進去，它整理出一張「語氣卡」，然後問你：這樣像你嗎？

不像就直接說哪裡不像，它會改。語氣卡可以一直調，不是一次定生死。

我沒有 10 篇貼文怎麼辦？

有幾篇貼幾篇。完全沒有的話，它會改成問你五個問題，一樣做得出語氣卡。

之後

學會語氣之後，就這樣用它

一樣不用記指令，用中文講就好。

這週要發什麼 問你目標，幫你排 3–5 篇的方向。每篇只鎖一個目標、一個公式、一個 CTA——想同時要觸及又要私訊又要賣課，結果是三個都拿不到。
幫我寫一篇，用我的口氣 一次給你 A／B／C 三組文案，每組都有標題、內文、置頂留言。你複製哪一組就去貼哪一個平台。
這篇為什麼沒人看 幫你分辨問題出在哪一層：推不出去？看不完？還是看完了沒人動作？這三種問題的解法完全不一樣，不要一律怪演算法。
💡 其他還能講：只要 Threads 版本、記錄成效：這篇觸及 3000、留言 12、這句不像我，我不會這樣講
卡關排除

常見問題

我的貼文和數據會被上傳嗎？

不會。語氣卡、內容方向、成效紀錄全部存在你自己電腦的技能資料夾裡，不會傳到任何伺服器。你可以自己打開那個資料夾看，裡面就是幾個純文字檔。

它真的不會自己去發文？

真的不會。它產出文案就停下來，等你自己複製去貼。程式裡完全沒有連到你社群帳號的功能，也沒有瀏覽器自動化。想確認的話，原始碼是公開的，可以自己看。

Claude Code 和 Codex CLI 我要選哪一個？

擇一即可，兩個都有也可以。同一份技能檔兩邊通用，安裝腳本會同時裝進兩個位置。已經在用 Claude 的人就用 Claude Code，習慣 OpenAI 的人就用 Codex CLI。

貼了指令，說「執行原則禁止載入檔案」或跳一大串紅字？

PowerShell 的執行原則擋住了。先關掉 PowerShell，改成用系統管理員身分重開一次再貼。還是不行就到小群裡把紅字截圖貼上來。

寫出來的東西還是很像 AI 怎麼辦？

八成是語氣卡沒學好。回去補幾篇樣本，或直接跟它說「這句不像我，我不會這樣講」，它會修正語氣卡再重寫一次。

可以用在我的商業帳號嗎？要錢嗎？

可以，而且技能本身免費。這是 MIT 授權的開源專案，自由使用、修改、商用都沒問題。你只需要負擔 Claude Code 或 Codex CLI 本身的費用。

用了就會爆款嗎？

不會。公式是提高機率，不是保證。新手最常見的失敗不是寫得不好，是發了三篇沒人看就停了。前兩週先求穩定發，不要求爆。

本技能改編自 駱君昊（Hao0321）的開源專案， 依 MIT 授權釋出，原授權檔完整保留。薇光版做的事是：拿掉自動發文與技術門檻、全面中文化、加上三組平台文案格式和給新手的公式。 原專案的成效數據屬於原作者本人帳號，不代表本版本的成效。引擎給你，數據要你自己跑出來。
